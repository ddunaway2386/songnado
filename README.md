# Songnado website

The public website for Songnado, served by GitHub Pages from `/docs`:

- Home page: https://ddunaway2386.github.io/songnado/
- Privacy policy: https://ddunaway2386.github.io/songnado/privacy/
- `docs/config/runtime.json`: the settings file the app reads on launch for service notices.
  The app expects it at this exact address, so don't move or rename it.

The app's code is kept in a separate private repository.
