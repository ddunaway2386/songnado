# Songnado Trademark Application — USPTO Filing Guide

USPTO TEAS Plus filing for "SONGNADO" to lock in priority date before launch. Cost: $250 per class (USPTO fee). Time: 6-12 months for full approval, but the priority date is set the day you file.

---

## What to file: TEAS Plus, Standard Character mark

**TEAS Plus** is the cheapest option ($250/class). Strict requirements: must use USPTO's pre-approved description list, must specify exact class(es), must be word mark or simple stylized mark.

**Standard Character format** — files just the WORD "Songnado" without any logo or styling. Protects the name no matter how it's stylized later. Pro: covers the name across any logo design you ever use. Con: doesn't protect the specific logo design (you'd file separately for that if needed).

For Songnado v1, **Standard Character** is the right starting point. Cover the name first, defend the logo specifically later if the design becomes valuable.

---

## Class selection — Class 9 only at start

USPTO has 45 classes covering different types of goods and services. For Songnado:

- **Class 9** (computer software, downloadable applications) — **primary, file this**
- **Class 41** (entertainment services) — optional, file later if needed

Class 9 covers "downloadable mobile applications for music trivia games" — that's the core of Songnado. Class 41 would cover services like running music trivia events, hosting tournaments, etc. — not your current business.

**Recommendation: file Class 9 only now.** $250 total. Add Class 41 later if you ever do live event/tournament business. Don't pay $500 today for coverage you don't use.

## Fields to fill in at uspto.gov

Go to: https://teas.uspto.gov → Filing forms → TEAS Plus

### 1. Mark Information

- **Type of mark**: Standard Character Mark
- **Mark literal element**: `SONGNADO`
- **Mark stylization**: None (plain text only)
- **Color claim**: No
- **Translation**: None (Songnado is a coined term — not from another language)

### 2. Owner / Applicant Information

- **Owner type**: Individual (assuming filing as Daniel personally; can transfer to LLC later if you form one)
- **Name**: Daniel Dunaway (use legal name as on ID)
- **Citizenship**: United States
- **Mailing address**: Daniel's home address
- **Email**: ddunaay@gmail.com
- **Phone**: Daniel's phone

If you form Songnado LLC before filing, file as the LLC instead. But individual filing is fine for indie launches — you can assign the mark to an LLC later via a simple Assignment of Trademark form.

### 3. Goods/Services (Class 9)

USPTO's pre-approved identification (use EXACTLY this wording to qualify for TEAS Plus discount):

> **Class 9:** Downloadable computer software for playing a music-themed trivia game; downloadable mobile applications for use in playing music-themed trivia and quiz games.

If the system gives you a search interface, search "music trivia downloadable software" and pick from the suggested list. The system enforces TEAS Plus rules automatically.

### 4. Filing Basis

- **Section 1(b) — Intent to Use** ✓ (you haven't launched yet; this is what you select)

Note: When you DO launch (within 6 months of approval), you'll file a "Statement of Use" with a specimen showing the mark on the app. USPTO sends a reminder. Don't forget to file this — failing to file kills the application.

### 5. Specimen

NOT required at filing for Intent-to-Use. Will be required at Statement of Use time (post-launch).

When required, the specimen will be either:
- A screenshot of the App Store listing showing "Songnado" prominently
- A screenshot of the app itself with the wordmark visible

## Timeline

| Step | When | What happens |
|---|---|---|
| **Day 0** | File application + pay $250 | Application enters USPTO queue |
| **~3-4 months** | Examiner review | USPTO examiner reviews. May ask clarifications (called "Office Actions"). For clean filings, often goes straight to publication. |
| **~5-6 months** | Published in Trademark Gazette | 30-day window for anyone to oppose. Highly unlikely for a coined name like "Songnado." |
| **~6-9 months** | Notice of Allowance issued | USPTO formally says "OK, we're ready to register — show us you're using it." |
| **Post-launch** | File Statement of Use + $100 | Provide a specimen (App Store screenshot). |
| **~9-15 months from filing** | Registration certificate issued | "SONGNADO ®" — fully registered |

Priority date is **the day you file**, not registration day. So filing now protects you from anyone who registers something similar between now and launch.
